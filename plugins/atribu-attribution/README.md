# atribu-attribution plugin

Claude Code plugin packaging the [Atribu attribution skill](skills/atribu-attribution/SKILL.md).

Installed automatically when you add the marketplace:

```
/plugin marketplace add AtribuCore/atribu-attribution-skill
/plugin install atribu-attribution@atribu-attribution
```

See the [top-level README](../../README.md) for full install + usage.
